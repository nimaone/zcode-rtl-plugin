# فیکس RTL زدکد — راست‌چین کردن متن فارسی در رابط چت ZCode دسکتاپ

[English](README.md) | [فارسی](#فارسی)

<a id="فارسی"></a>

**ZCode دسکتاپ** (اپ رایگان کدنویسی با هوش مصنوعی از Z.ai) متن فارسی چت را چپ‌چین و با ترتیب کلمات به‌هم‌ریخته نشان می‌دهد. اپ هیچ گزینه‌ای برای RTL ندارد و سیستم پلاگین آن هم رسماً اجازهٔ تغییر ظاهر خود اپ را نمی‌دهد — پس این پلاگین از مطمئن‌ترین راه می‌رود: یک فیکس جهت متنِ آزمون‌پس‌داده را از طریق پروتکل استاندارد دیباگ کرومیوم (CDP) داخل اپِ در حال اجرا تزریق می‌کند. **هیچ فایلی از خود ZCode تغییر داده نمی‌شود**، به همین دلیل این فیکس با آپدیت‌های اپ از کار نمی‌افتد.

## چه چیزی دریافت می‌کنید

| بخش | رفتار |
|---|---|
| متن فارسی در چت | RTL و راست‌چین (بر اساس نسبت حروف فارسی؛ بلاک‌های «تفکرات» عمدتاً انگلیسی، LTR می‌مانند) |
| بلاک‌های کد و دستورهای ترمینال | LTR و دست‌نخورده |
| بلاک‌های ابزار (ترمینال / تفکر / ادیت) | ظاهر و چیدمان بلاک LTR می‌ماند؛ متن فارسی داخل بدنه RTL می‌شود |
| جدول‌ها | کاملاً RTL (ستون اول سمت راست)، مقادیر طولانی می‌شکنند به‌جای سرریز |
| حباب پیام کاربر | سمت راست؛ پیام دستیار سمت چپ |
| سایدبار اپ | کاملاً دست‌نخورده |

payload حین استریم‌شدن جواب مدل خودش را ترمیم می‌کند (اسکن با تأخیر ۲۰۰ میلی‌ثانیه)، پس متنی که وسط جواب تولید می‌شود بلافاصله درست می‌شود.

## پیش‌نیازها

- **ZCode دسکتاپ** برای ویندوز (این راهنما ویندوز‌محور است؛ روی macOS/Linux خود تزریق‌کننده کار می‌کند — بخش [نصب دستی](#نصب-دستی-بدون-شورتکات) را ببینید)
- **Node.js نسخه ۲۲ به بالا** (با `node --version` چک کنید)

## نصب (۳ قدم)

### قدم ۱ — این ریپو را به‌عنوان مارکت‌پلیس پلاگین اضافه کنید

در ZCode به مسیر زیر بروید:

**Plugin Marketplace ← Add ← Add Plugin Marketplace**

و این آدرس را قرار دهید:

```
https://github.com/nimaone/zcode-rtl-plugin
```

### قدم ۲ — پلاگین را نصب کنید

مارکت‌پلیسی که اضافه کردید را باز کنید (تب **Personal**)، پلاگین **ZCode RTL Fix** را پیدا و **Install** کنید. بعد از نصب باید آن را در **Settings ← Plugin Management ← Installed** ببینید.

### قدم ۳ — ZCode را با شورتکات مخصوص اجرا کنید

تزریق به پورت دیباگِ باز نیاز دارد. یک بار شورتکات را بسازید — پوشهٔ پلاگین نصب‌شده را پیدا کنید (کش نصب):

```
%USERPROFILE%\.zcode\cli\plugins\cache\<marketplace>\zcode-rtl\<version>\
```

و این دستور را در PowerShell اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<مسیر پوشه پلاگین>\scripts\make-shortcut.ps1"
```

این کار شورتکات **ZCode (RTL)** را روی دسکتاپ می‌سازد. از این به بعد ZCode را همیشه با همین شورتکات باز کنید (دابل‌کلیک کافی است؛ اگر نمونه‌ای بدون پورت باز در حال اجرا باشد خودش می‌بندد و درست دوباره باز می‌کند). یک watcher مخفی فیکس را بعد از هر بارگذاری مجدد رابط دوباره تزریق می‌کند و یک هوک SessionStart هم در شروع هر session به‌عنوان لایهٔ دوم اطمینان، فیکس را دوباره اعمال می‌کند.

تمام — از این به بعد پیام‌های فارسی RTL نمایش داده می‌شوند.

> اگر ZCode.exe در مسیر غیراستاندارد نصب شده و لانچر پیدایش نکرد، یک بار دستی اجرا کنید:
> `powershell -File start-rtl.ps1 -ZCodeExe "C:\مسیر\به\ZCode.exe"`

## استفادهٔ روزمره

- **دستور /rtl-fix** — داخل ZCode تایپ کنید: فیکس را دوباره اعمال می‌کند یا گزارش وضعیت می‌دهد.
- **بعد از آپدیت ZCode** — اگر چیدمان دوباره به‌هم ریخت، فقط `/rtl-fix` را اجرا کنید. اگر آپدیت نام کلاس‌های DOM را عوض کرده باشد، از ایجنت ZCode بخواهید سلکتورهای `assets/zcode-rtl-fix.js` را به‌روز کند (اسکیل `zcode-rtl` همراه پلاگین یک کتابچهٔ ترمیم کامل دارد، شامل نقشهٔ ساختار DOM فعلی).

## نصب دستی (بدون شورتکات)

هر پلتفرمی:

```bash
# ابتدا ZCode را ببندید، سپس با پورت دیباگ اجرا کنید
zcode --remote-debugging-port=9222 &        # یا مسیر کامل فایل اجرایی

# فیکس را فعال نگه دارید
node <مسیر پوشه پلاگین>/scripts/inject-rtl.mjs --watch
```

اگر watcher نمی‌خواهید، `--watch` را حذف کنید (با `--verbose` لاگ می‌گیرید). برای بررسی وضعیت `--status` و برای دست‌کاری زندهٔ DOM از `--eval "<js>"` استفاده کنید.

## چطور کار می‌کند (خلاصه)

اسکریپت `scripts/inject-rtl.mjs` یک کلاینت CDP با Node و بدون هیچ وابستگی خارجی است. از طریق `http://127.0.0.1:9222/json/list` همهٔ صفحات رندرکننده را پیدا می‌کند، با WebSocket وصل می‌شود و `assets/zcode-rtl-fix.js` را داخل صفحه اجرا می‌کند (در حالت watch با `Page.addScriptToEvaluateOnNewDocument` تا بعد از reload هم باقی بماند). payload جهت هر المان را جداگانه تصمیم می‌گیرد: متن‌های فارسی‌غالب `direction: rtl` می‌گیرند، متن لاتین و کد LTR می‌مانند، سایدبار و ظاهر بلاک‌های ابزار صراحتاً مستثنا شده‌اند و یک `MutationObserver` نودهای تازهٔ استریم‌شده را دوباره پردازش می‌کند. چون فقط استایل زنده را دست می‌زند، هیچ‌وقت فایلی از اپ را روی دیسک تغییر نمی‌دهد.

**نکتهٔ امنیتی:** پورت دیباگ فقط روی `127.0.0.1` باز می‌شود و فقط از خود سیستم قابل دسترس است. آن را فوروارد نکنید. این یک تزریق استایل سمت کاربر است، نه دستکاری اپ.

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `/rtl-fix` می‌گوید پورت بسته است | ZCode را کامل ببندید (از tray ← Quit) و با شورتکات **ZCode (RTL)** بازش کنید |
| بعد از اجرای مجدد، فارسی هنوز LTR است | یک بار `/rtl-fix` اجرا کنید — ممکن است هوک قبل از بازشدن پنجره اجرا شده باشد |
| بعد از آپدیت ZCode چیدمان به‌هم ریخت | `/rtl-fix`؛ اگر درست نشد یعنی DOM عوض شده — سلکتورهای payload را به‌روز کنید (بخش اسکیل) |
| بعد از ری‌استارت سیستم watcher نیست | با شورتکات **ZCode (RTL)** باز کنید؛ هوک SessionStart هم sessionها را پوشش می‌دهد |
